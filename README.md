# ZaferYilmaz.net

Official personal website of **Zafer Yilmaz**, an International Business Development and Growth Strategist specializing in helping companies achieve sustainable success across global markets.

**Live Website:** https://zaferyilmaz.net

---

## Overview

This website serves as my professional online presence, introducing my background, expertise, speaking activities, and providing a direct way to get in touch.

The project was intentionally built without frameworks to keep it lightweight, maintainable, and fast.

---

## Features

- Responsive design
- Light/Dark theme with user preference persistence
- Progressive Web App (PWA)
- Offline support through Service Worker
- Contact form powered by Formspree
- Open Graph and X (Twitter) social sharing support
- Search engine optimized (SEO)
- Accessible semantic HTML
- No external JavaScript frameworks

---

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- Formspree
- Progressive Web App (PWA)

## Contact Form

The contact form is powered by **Formspree** and submits messages asynchronously using the Fetch API, allowing visitors to remain on the website while receiving immediate feedback about the submission status.

---

## Performance

The website is designed to be lightweight and efficient.

- Minimal dependencies
- Optimized asset caching
- Installable as a Progressive Web App
- Fast loading on desktop and mobile devices
